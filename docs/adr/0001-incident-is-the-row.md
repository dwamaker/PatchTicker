# One row per Incident, not per CVE

One real-world event often shows up as a write-up site, a repository, a forum thread and one or more CVEs, and the CVE can arrive hours after everything else (sshole on 2026-11-05 had no CVE in its own repo or site; CVE-2026-123158 appeared later). So the Board shows one row per Incident, Mentions and CVEs hang off it, and an Unassigned incident is shown at once and merged when its CVE lands. Rows keyed by CVE would be simpler but would split one event across rows and hide the earliest, most useful hours.
